Put your files here:

assets/audio/1 bullet.wav
assets/audio/auto bullet.MP3
assets/audio/gun reload.mp3
assets/audio/hitmarker.mp3
assets/models/ak47.glb   (or FPS_AK-74m_animations.glb)
assets/models/bot.glb
assets/textures/ground.jpg, wall.jpg, cover.jpg   (optional, .png also works)

Any missing file is replaced by a procedural fallback, so the game always runs.
